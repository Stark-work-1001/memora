# Delivery and redaction / 交付与脱敏

开发、自用资料与公开产物分开。自用版可选择自己的资料、模型、工具和组织配置；公开目录不是
自用目录的整体复制。交付路径由本机构建调用确定，本文只写相对目录，不发布开发机绝对路径。

## 按用户提供指南落实

用户提供的《数据脱敏指南》仅在私有开发环境读取，不随项目再分发。落实为：

- 无公开许可、无授权、无需交付的材料全部排除，包括原始参考压缩包、站点抓取构建块和原始聊天。
- 明确白名单构建源码；不复制 `.git`、虚拟环境、运行库数据、配置、模型权重、缓存、截图或构建日志。
- 测试数据为合成样例；有必要的字段使用一致的虚构标识，保留日期、来源和关系结构；无必要个人
  内容直接删除，不依赖肉眼不可见遮盖。
- 检查姓名 / 账号 / 联系方式 / 私有组织信息 / 本机目录与用户名 / 内部端点 / API 密钥 / 连接串；
  检查组合特征与文档元数据。开发机已知路径和令牌模式在文本、嵌入 WASM、二进制和压缩包中扫描。
- Rust 使用编译路径映射；Python 冻结模块检查 code filename；原复制 WASM 的编译目录标识已去除。
- 保留依法需要的开源许可与已公开版权署名。仓库公开发布者名称、项目链接、上游作者署名不属于
  本机构建时应随意抹除的私人聊天数据。

## 交付内容

| 内容 | 面向对象 | 入口 |
|---|---|---|
| sanitized public source | GitHub 仓库读者 / 开发者 | README.md / README.zh-CN.md |
| memora-1.0.1-windows-x64.zip | Windows x64 使用者 | 解压后 Memora.exe |
| memora-1.0.1-source.zip | 源码复现 | 两份仓库 README、源码、测试与许可 |
| RELEASE_NOTES.*.md | 发行版使用者 | 安装、升级、版本变化与限制 |
| RELEASE_VALIDATION.json | 验收人员 | 测试计数、隐私检查结果与限制 |
| SMOKE_VALIDATION.json | 验收人员 | 冻结后端、Rust、MCP 和桌面启动验证 |
| RELEASE_MANIFEST.json / SHA256SUMS | 完整性核查 | 源码逐文件哈希 / 压缩包 SHA-256 |

旧版 1.0.0 基线独立保留，不覆盖。公开目录旧内容先保存在私有开发 artifacts 下，再用白名单
源码重建；旧目录的 Git 历史不混入脱敏仓库。更改与验收点见 [CHANGELOG](../CHANGELOG.md) 和
[ITERATION_1.0.1](ITERATION_1.0.1.md)。

模式扫描与人工结构审查有边界，不能保证自动识别所有语义上的隐私。交付报告记录实际检查结果，
不宣称法律合规认证。GitHub 上传前请用户确认版本功能、公开目录与发行包脱敏是否达标；目前
仅生成本地可审阅产物，不自动提交、推送或创建 Release，也不新增第三方授权。
